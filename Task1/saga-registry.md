| Транзакция | Описание                                                                                                                                                                                                               | Тип | Компенсация |
|---|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---|---|
| `CREATE_PAYMENT` | Создание записи платежа и запуск Saga-оркестрации                                                                                                                                                                      | Компенсируемая | `CANCEL_PAYMENT` |
| `DEBIT_FUNDS` | Списание (холдирование) средств со счёта клиента                                                                                                                                                                       | Компенсируемая | `REFUND_FUNDS` |
| `FRAUD_CHECK` | Проверка антифрод: внутренние правила + внешние провайдеры (AML, GeoRisk)                                                                                                                                              | Повторяемая | - |
| `MANUAL_REVIEW` | Постановка транзакции на ручное рассмотрение оператору                                                                                                                                                                 | Повторяемая | - |
| `TRANSFER_TO_CONTRACTOR` | Перевод средств контрагенту                                                                                                                                                                                            | Необратимая | - |
| `COMPLETE_PAYMENT` | Фиксация финального статуса платежа                                                                                                                                                                                    | Повторяемая | - |
| `SEND_NOTIFICATION` | Уведомление клиента о статусе операции                                                                                                                                                            | Повторяемая | - |
| `NOTIFY_SECURITY` | Уведомление системы безопасности о подозрительной операции для анализа                                                                                                                                                 | Повторяемая | - |
| `CANCEL_PAYMENT` | Компенсация `CREATE_PAYMENT`: перевод платежа в терминальный статус, откат состояния Saga                                                                                                          | Повторяемая | - |
| `REFUND_FUNDS` | Компенсация `DEBIT_FUNDS`: автоматический возврат средств клиенту                                                                                                                                                      | Повторяемая | - |
